# セットアップ手順

サイトをスプレッドシートにつなぐための初回設定です。
**ブラウザでの操作だけ**で終わります。所要 30〜40分。

途中で分からなくなっても、**設定が終わるまでサイトは「お試しモード」で普通に動きます。**
慌てずに進めてください。

---

## 目次

1. スプレッドシートを作る
2. Apps Script にプログラムを貼る
3. `setup()` を実行してシートを作る
4. ウェブアプリとして公開する
5. Google Cloud Console でサインインの設定をする
6. `index.html` に2つの値を書き込む
7. 動作確認

---

## 1. スプレッドシートを作る

1. Googleドライブを開く
2. 左上「＋ 新規」→「Google スプレッドシート」
3. 左上のファイル名を **「大会情報ポータル データ」** に変更

---

## 2. Apps Script にプログラムを貼る

1. スプレッドシートのメニュー **「拡張機能」→「Apps Script」**
2. 新しいタブが開き、`function myFunction() {}` と書かれたエディタが出ます
3. **その中身を全部消して**、`Code.gs` の中身を丸ごと貼り付け
4. 貼り付けたら、上のほうにある2か所を書き換えます

```js
var GOOGLE_CLIENT_ID = 'ここにクライアントIDを貼る.apps.googleusercontent.com';

var ALLOWED_EMAILS = [
  'ここに管理者のメールアドレス@gmail.com'
];
```

- `ALLOWED_EMAILS` … **いま自分が使っているGoogleアカウントのメールアドレス**を入れてください。
  複数人で管理するなら、カンマで区切って何行でも足せます。
- `GOOGLE_CLIENT_ID` … **手順5で作ります。いまは触らなくてOK**です。

5. 💾（保存）を押す

```
  ┌──────────────────────────────────────┐
  │ Apps Script                     💾  ▶ 実行  │
  ├──────────────────────────────────────┤
  │ 1  var GOOGLE_CLIENT_ID = '……';      │
  │ 2  var ALLOWED_EMAILS = [            │
  │ 3    'jimukyoku@gmail.com'   ← ここ  │
  │ 4  ];                                │
  └──────────────────────────────────────┘
```

---

## 3. `setup()` を実行してシートを作る

1. エディタ上部の関数リスト（`▶ 実行` の左）で **`setup`** を選ぶ
2. **`▶ 実行`** を押す

初回は許可を求められます。**ここが一番つまずくところです。**

```
  「このアプリはGoogleで確認されていません」
        ↓
  左下の【詳細】をクリック
        ↓
  【（安全ではないページ）に移動】をクリック
        ↓
  【許可】
```

> ⚠️ 「安全ではないページ」と出ますが、**自分で書いたプログラムなので問題ありません。**
> ここで引き返すと先に進めません。

実行が終わると「セットアップが完了しました」と出て、スプレッドシートに
**大会 / 選手 / 結果 / お知らせ / 設定** の5枚のシートができています。

---

## 4. ウェブアプリとして公開する

1. Apps Script エディタの右上 **「デプロイ」→「新しいデプロイ」**
2. 左上の ⚙️（歯車）→ **「ウェブアプリ」** を選ぶ
3. 次のように設定します

| 項目 | 設定 |
|---|---|
| 説明 | `v1`（なんでもOK） |
| 次のユーザーとして実行 | **自分** |
| アクセスできるユーザー | **全員** |

> 「全員」で不安になるかもしれませんが、**読み取りだけが全員に許可される**設定です。
> 書き込みは `ALLOWED_EMAILS` のアカウントしかできません。サイトを誰でも見られるようにするために必要です。

4. **「デプロイ」** を押す
5. 出てきた **ウェブアプリのURL** をコピーしてメモ帳などに控える

```
https://script.google.com/macros/s/AKfycb.................../exec
                                    ↑ この長いURL全部
```

---

## 5. Google Cloud Console でサインインの設定をする

管理画面に入るときの「Googleでログイン」を使えるようにします。

### 5-1. プロジェクトを作る

1. https://console.cloud.google.com/ を開く
2. 上部のプロジェクト選択 →「新しいプロジェクト」
3. 名前は `bound-tennis-portal` など。作成

### 5-2. OAuth同意画面

1. 左メニュー **「APIとサービス」→「OAuth同意画面」**
2. User Type：**外部** → 作成
3. アプリ名：`大会情報ポータル`／ユーザーサポートメール：自分のアドレス／デベロッパーの連絡先：自分のアドレス
4. あとは「保存して次へ」を押していく（スコープは何も足さなくてOK）
5. **公開ステータスは「テスト」のままで構いません。**
   「テストユーザー」に管理者のメールアドレスを追加してください。

### 5-3. クライアントIDを作る

1. 左メニュー **「APIとサービス」→「認証情報」**
2. 上部 **「＋ 認証情報を作成」→「OAuth クライアント ID」**
3. アプリケーションの種類：**ウェブアプリケーション**
4. **承認済みの JavaScript 生成元** に、サイトのURLを追加します

```
https://ユーザー名.github.io
```

> ⚠️ **ここが間違えやすい点です。**
> - `https://` から始めて、**末尾にスラッシュを付けない**
> - リポジトリ名（`/bound-tennis` など）は **付けない**。ドメインまでです
> - 動作確認をローカルでもするなら `http://localhost:8000` も足しておく

5. 「作成」を押すと **クライアントID** が表示されます。控えてください

```
1234567890-abcdefg.apps.googleusercontent.com
```

### 5-4. クライアントIDを Code.gs にも入れる

1. Apps Script のエディタに戻る
2. `GOOGLE_CLIENT_ID` に、いま作ったクライアントIDを貼る
3. 💾 保存
4. **「デプロイ」→「デプロイを管理」→ 鉛筆マーク → バージョン「新バージョン」→ デプロイ**

> ⚠️ **Code.gs を直したら、必ずこの再デプロイをしてください。**
> 保存しただけでは公開中のプログラムは変わりません。
> なお、この方法で更新すればURLは変わりません。「新しいデプロイ」を選ぶとURLが変わってしまうので注意。

---

## 6. `index.html` に2つの値を書き込む

`index.html` をテキストエディタで開き、**上のほう（`設定` と書いてあるところ）** を書き換えます。

```js
const SHEETS_API_URL = 'https://script.google.com/macros/s/AKfycb..../exec';
const GOOGLE_CLIENT_ID = '1234567890-abcdefg.apps.googleusercontent.com';
```

- `SHEETS_API_URL` … 手順4で控えたURL
- `GOOGLE_CLIENT_ID` … 手順5-3で控えたクライアントID

GitHub上で直接編集できます。ファイルを開いて **鉛筆アイコン → 編集 → Commit changes**。

---

## 7. 動作確認

1. サイトを開いて **Ctrl+F5**（Macは Cmd+Shift+R）で強制再読み込み
2. 画面が普通に出ればデータの読み込みは成功
3. フッターの **「管理者向けログイン」** をクリック
4. **Googleのサインインボタン**が出ればOK（お試しモードの案内が出ていたら手順6の値が入っていません）
5. サインインして管理画面へ。右上が **「サーバー接続中」** になっていることを確認
6. なにか1つ直して **「保存する」** → スプレッドシートに反映されていれば完了

---

## うまくいかないとき

**「このGoogleアカウントには編集権限がありません」と出る**
→ `Code.gs` の `ALLOWED_EMAILS` にそのアドレスが入っているか確認。
　直したら **再デプロイ**（手順5-4）を忘れずに。

**サインインボタンが出ない／押しても何も起きない**
→ 「承認済みのJavaScript生成元」のURLが違います。末尾のスラッシュ、リポジトリ名の付け忘れ／付けすぎを確認。
　直してから5分ほど待つと反映されます。

**サイトにデータが出ない（前の内容が出る）**
→ 画面下に「サーバーにつながらないため、前回読み込んだ内容を表示しています」と出ていませんか。
　`SHEETS_API_URL` が間違っているか、デプロイの「アクセスできるユーザー」が「全員」になっていません。

**保存を押すと「通信に失敗しました」**
→ 内容はこの端末に残っているので消えていません。電波のよい場所でもう一度「保存する」を押してください。

**Code.gs を直したのに反映されない**
→ 再デプロイ（手順5-4）をしていません。ここは本当によく忘れます。
