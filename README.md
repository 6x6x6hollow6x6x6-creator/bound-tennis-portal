# 大会情報ポータル / BTPランキング

全国のバウンドテニス大会の情報を集約し、その結果から日本ランキング（BTP）を算出するサイトです。
**サーバー代・ドメイン代ゼロ。** GitHub Pages + Googleスプレッドシート + Googleドライブで動きます。

```
リポジトリ/
├─ index.html              ← サイト本体＋管理画面（これ1つで動きます）
├─ apps-script/
│  ├─ Code.gs              ← スプレッドシートAPI（Apps Scriptに貼る）
│  └─ セットアップ手順.md   ← 初回のブラウザ操作の手引き
├─ 運用マニュアル.md        ← 更新担当者向け
└─ README.md
```

## いますぐ見る

`index.html` をダブルクリックするだけで動きます。
**Apps Script も スプレッドシートも Googleドライブも未設定で構いません。**
コードの中にサンプルデータが入っているので、そのまま全画面を確認できます。

管理画面も試せます。フッターの「管理者向けログイン」→「お試しモードで管理画面を開く」。
この状態での編集内容は、その端末のブラウザにだけ保存されます。

## 本番につなぐ

`apps-script/セットアップ手順.md` のとおりに進めて、最後に `index.html` の先頭付近にある
2つの値を書き換えるだけです。

```js
const SHEETS_API_URL   = 'https://script.google.com/macros/s/..../exec';
const GOOGLE_CLIENT_ID = '....apps.googleusercontent.com';
```

この2つが入った瞬間から、データはスプレッドシートを見に行くようになり、
管理画面のログインもGoogleサインインに切り替わります。**コードの書き換えはここだけです。**

## データの読み込み方（3段構え）

1. Apps Script API から取得
2. 失敗したら localStorage のキャッシュ（前回の内容を表示）
3. それも無ければ `DEFAULT_DATA`（コードに埋め込んだサンプル）

通信が切れても、設定が済んでいなくても、画面が真っ白にならない作りです。

## 公開する

GitHub の **Settings → Pages** で

- Source: `Deploy from a branch`
- Branch: `main` / フォルダ: `/ (root)`

数分で `https://ユーザー名.github.io/リポジトリ名/` に出ます。
非公開リポジトリから Pages を出すには GitHub の有料プランが必要です。
無料で済ませるならリポジトリを Public にするか、Cloudflare Pages を使ってください。

## ランキングの仕組み

- 直近52週のローリング集計
- 獲得ポイントの上位6大会を合計。ただし G4・G5 は合わせて最大2大会まで
- ポイント ＝ グレード別の配点 × ドロー係数（32名以上1.00／16〜31名0.85／8〜15名0.70／4〜7名0.50）
- 区分は 種目 × 性別 × カテゴリ。ミックスダブルスは男女共通の1区分
- ミドル・シニアの選手がフリーの部に出た成績は、両方のランキングに算入
- 掲載条件は期間内2大会以上の出場

順位の変動（▲▼）と推移グラフは、**過去12か月それぞれの時点で同じ集計をやり直して**出しています。
履歴を保存する必要がないので、担当者が「順位を確定する」ような操作をしなくて済みます。

配点・集計ルールはすべて管理画面の「配点・集計」タブから変更できます。

## 技術メモ

- ビルド工程なし。CDN（Tailwind / lucide / Google Identity Services）のみ
- POSTは `Content-Type: text/plain;charset=utf-8`。Apps Script はプリフライトに応答できないためCORSを回避し、受け側で `JSON.parse` する
- 管理画面から入った文字列は `esc()` を通してから DOM に入れる。`href` は `safeUrl()` で `https?:` のみ許可
- 書き込み権限は Apps Script 側の `verifyIdToken_()` で判定する。`aud` の一致・`email_verified`・`ALLOWED_EMAILS` の3つを見る。フロント側の制御は目隠しにすぎないので、**サーバー側の判定が本体**
- 結果シートは1行1名。増えても重くならないよう、GETに `&since=YYYY-MM-DD` で期間を絞る口を用意してある

## 注意

- いま入っているのは**すべて架空のサンプルデータ**です。本番前に入れ替えてください
- ヘッダーのロゴはプレースホルダーです。協会の正規ロゴに差し替えてください
- 本番公開時は、管理画面の「サイト文言」で上部の注意バーを空欄にしてください
