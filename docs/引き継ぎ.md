## 制度の方針転換（2026-08-18）

依頼者から実態の説明があり、前提が違っていたことが分かった。

> 交流大会は大会ごとに内容が違い、**クラス分けがない大会が多い**。
> 全国で行われる大会の9割は地方の交流大会で、公式戦と言えるのは
> 全国大会（本戦・県予選）、ブロック選手権（本戦・県予選）、県選手権、
> 国民スポーツ大会（団体戦のみ）くらいしかない。

元の設計は「ローカル大会の成績も同じ物差しで比較できる」前提に立っていたが、
クラス分けが無ければ優勝の意味が大会ごとに違うので、その前提は成り立たない。
配点表もドロー係数も、クラス分けとブラケットがある大会でなければ機能しない。

**決定：ランキングは公式戦だけで組み、交流大会は掲載にとどめる。**

| 項目 | 変更前 | 変更後 |
|---|---|---|
| G4・G5の配点 | 90〜180pt | **すべて0**（掲載のみ） |
| 有効大会数 | 上位6大会 | **4大会**（公式戦は年に数回しかない） |
| 掲載条件 | 2大会以上の出場 | **1大会以上** |
| 対象種目 | 全種目 | **シングルス・ダブルス・ミックスダブルス**（`settings.rankEvents`） |

団体戦は掲載できるようにしたが、ランキングには算入しない。
出場していない控えの選手にも順位が付いてしまい、貢献度を測れないため。
チーム単位の団体戦ランキングを別立てにするかは未決（下の未決事項）。

実装上の要点：

- 配点0のグレードは `computeRankings` が結果ごとスキップするので、集計から完全に外れる
  （出場回数にも数えられない）。設定を戻せば元の挙動に戻る
- 制度ページの「掲載のみ」バッジと文言は、**配点から自動判定**している。
  固定テキストに書くと設定を変えたときに食い違うので、書かないこと
- 種目は2本立て。`EVENTS_ALL`（掲載できる種目・団体戦とBTラリー戦を含む）と
  `settings.rankEvents`（ランキング対象）
- 管理画面の結果登録で、対象外の種目を選ぶとポイント欄が「—」になり
  「ランキングには算入されません」と出る。数字を見せると誤解を生むため

ついでに直した既存の不具合：種目がBTラリー戦だけの大会を選ぶと、種目の選択肢が空のまま
登録でき、`ev` が空文字の結果ができてしまっていた。保存を止めるようにした。

## 地域差・ドロー数の是正（2026-08-18）

依頼者からさらに指摘があった。

> ブロックや都道府県でレベルや参加人数に偏りがある。北海道はブロック大会も北海道だけで
> くくられているので有利になる。地域によっては参加した瞬間に入賞が決まることもある。

調べたところ、係数表に穴があって実際に順位が逆転していた。

```
修正前
  G2 2名ドローで優勝（1試合勝つ）      = 300 pt
  G3 32名ドローで優勝（5試合勝つ）      = 360 pt   ← ほぼ同じ
  G2 4名ドローで初戦負け（ベスト4確定） = 135 pt
  G3 32名ドローでベスト8（3試合勝つ）   = 101 pt   ← 負けた人のほうが高い
```

原因は2つ。**係数表の最小バケットが「4名以上」しかなく、それ未満は全部0.50に落ちていた**こと
（`drawCoef` は最小バケット未満のとき最後の行の係数を返す。1名でも0.50）。
もう1つは、**成績ラベルが「何人抜いたか」の代理指標として機能していない**こと。

対処（すべて実施済み）：

1. **勝ち数0の成績は「出場」に読み替える**（`winsNeeded()` / `awardedPoint()`）。
   ドロー数と成績から必要勝ち数を計算できる（32名ドローの優勝＝5勝、4名ドローのベスト4＝0勝）。
   設定 `winBasedPlaces` を false にすると元の挙動に戻る
2. **係数表に `2名以上＝0.30` を追加**して下限を作った
3. **グレードは競う範囲で決めるルールを制度ページに明記**（`about.gradeRule`）。
   実質1県のブロック大会はG3として扱う。コード変更ではなく運用ルール

```
修正後
  G2 2名ドローで優勝                    = 180 pt
  G2 4名ドローで初戦負け                =   9 pt   ← 出場扱いになった
  G3 32名ドローでベスト8（3試合勝つ）   = 101 pt   ← 逆転が解消
```

あわせて、**ドロー数未入力（0）だと係数0.50が黙って適用されていた**問題も直した。
事務局が入力を忘れると半分のポイントが付いてしまう状態だったので、登録時に弾くようにし、
入力欄にも警告を出すようにした。

スモークテストに「勝ち数0の入賞は出場扱い」「勝った選手のほうが点が高い」を追加してある。
